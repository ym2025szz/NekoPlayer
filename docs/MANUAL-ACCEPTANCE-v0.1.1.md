# 猫娘播放器 v0.1.1 人工播放验收

## 一、启动方式

运行：

```text
<项目目录>\artifacts\publish\win-x64\NekoPlayer.exe
```

## 二、导入测试音频

进入“本地音乐”页面，点击“添加文件夹”，选择：

```text
<测试音频目录>
```

测试音频只用于本地人工验收，不会被复制到源码或最终发布目录。

## 三、人工测试清单

- [ ] 1. 应用能正常启动。
- [ ] 2. 设置页面显示 FFmpeg 可用、版本正确、Shared DLL 完整。
- [ ] 3. 可以导入测试音频文件夹。
- [ ] 4. 两首 MP3 均显示在音乐库。
- [ ] 5. 歌名、歌手、专辑和时长显示合理。
- [ ] 6. 双击第一首可以播放。
- [ ] 7. 扬声器或耳机能够听到声音。
- [ ] 8. 播放进度正常移动。
- [ ] 9. 点击暂停后声音停止。
- [ ] 10. 暂停后进度基本停止。
- [ ] 11. 再点击播放后从暂停位置继续。
- [ ] 12. 拖动进度条后可以从目标位置继续播放。
- [ ] 13. 点击下一首后切换为第二首。
- [ ] 14. 切歌时没有上一首残留声音。
- [ ] 15. 点击上一首逻辑正常：超过 3 秒先回到开头，否则切换上一首。
- [ ] 16. 音量滑块有效。
- [ ] 17. 静音按钮有效。
- [ ] 18. 歌曲封面正常显示，或显示默认猫耳音符封面。
- [ ] 19. 如果存在同名 LRC，歌词能够加载。
- [ ] 20. 正在播放页面频谱能够运动。
- [ ] 21. 暂停后频谱行为符合设计。
- [ ] 22. 连续快速切换几次歌曲不会崩溃。
- [ ] 23. 关闭应用后没有残留声音。
- [ ] 24. 重新启动后队列和上次位置能够恢复。
- [ ] 25. 重新启动后不会自动发声。

## 六、说明

- 技术播放验证已经检查 FFmpeg、PCM、NAudio 调用、暂停、Seek、切歌与资源释放，但不能代替人工听感验收。
- 日志可能包含本地音乐路径，不建议公开上传未经检查的完整日志。
- 出现问题时请保留最新日志和 `artifacts\test-reports` 中的验证报告。
- 不要删除或修改测试音频。
- 人工验收结束前暂不开发下一阶段。
