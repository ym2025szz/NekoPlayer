# 猫娘播放器 v1.1.0 发布说明

v1.1.0 新增网易云音乐、QQ 音乐、酷我音乐、酷狗音乐与汽水音乐在线网关及应用管理的 Node 子进程，同时保留本地导入、SQLite 曲库、FFmpeg/NAudio 播放、歌词、收藏、最近播放、自建歌单、队列与默认封面。

在线歌曲按平台与稳定歌曲身份保存；播放时解析当前可用媒体来源。平台的搜索与音源服务可能受网络、账号、内容授权或上游接口变化影响。无可用音源或网关运行时不可用时，应在在线操作中报告对应状态，本地功能继续可用。

五个平台统一通过本机 Node 网关访问。网易云与 QQ 音乐是优先验证链路，酷我游客 HTTP 适配器也已通过本轮指定样例的搜索、歌词与有界媒体解码。网易云部分曲目只提供试听，音源须逐首验证。酷狗与汽水目前受游客权限或限流限制；接入和有限解码检查均不等于已验证所有曲目或整首连续播放。

## 运行与发布变化

- 内置 Node.js v24.21.0 Windows x64 从官方 ZIP 安装，校验固定 SHA-256 和官方 HTTPS 校验表，并保留完整原始 LICENSE；无需用户安装全局 Node。
- `setup-music-gateway.ps1` 使用内置 npm，依据锁文件安装运行依赖，禁用依赖生命周期脚本。首次安装需要网络；完成的发布包启动不执行 npm 或运行时下载。
- Windows x64 self-contained 包携带 FFmpeg Shared、网关源码、运行依赖、Node、来源、锁文件与许可证。
- 版本主来源为 App 项目的 `Version`；程序集、界面与日志读取同一版本，发布脚本校验 EXE 文件版本和产品版本。
- 发布复制限制到本项目指定运行时目录，排除测试音频、测试夹具、用户数据与凭据，并生成逐文件 `runtime-manifest.json`。
- Release 的 Avalonia.Diagnostics 依赖与文件均在发布中检查排除。
- 搜索历史支持选用、单条删除和清空；最近播放继续支持单条移除、撤销和确认后清空。
