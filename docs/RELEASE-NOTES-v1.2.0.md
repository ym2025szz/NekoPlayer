# v1.2.0

本次正式版完善日常播放、歌词、队列和桌面控制，并修复单曲循环在真实解码结束后不再重播的问题。

- 完整歌曲的单曲循环每轮重新加载音频；在线歌曲每轮重新取得播放地址。过期地址只允许刷新一次，重试失败保留当前歌曲的错误状态，不自动跳到队列下一首。试听结束停止播放。取消加载、切歌或退出时清理解码进程，不把取消后的 FFmpeg 探测错误显示成播放故障。
- 歌词支持按当前播放时间定位、跟随滚动、双击跳转及重试；试听片段按可播放区间显示歌词。桌面歌词提供独立窗口及显示设置。
- 增加托盘控制、窗口关闭后的后台行为和明确退出入口；同一 Windows 用户、同一数据目录只运行一个实例。更新退出命令等待播放、网关和应用服务完成清理。
- 增加 Windows 系统媒体控件与媒体键控制，可同步当前歌曲、播放状态和已缓存封面；可在设置中开关。无法初始化时仍可使用播放器窗口操作。
- 增加睡眠定时器，到期暂停播放；队列支持调序、清理待播歌曲和定位当前歌曲。操作保持当前播放歌曲。
- 歌单支持筛选、全部播放、加入队列、调整顺序和移除后的短时撤销；持久化顺序与用户操作顺序保持一致。
- 在线播放的账号授权入口按平台独立定位。授权凭证仍使用当前 Windows 用户的 DPAPI 加密存储，不包含在发布包中。
- Windows x64 正式包使用自包含 .NET 8 运行时，目标 Windows SDK 为 19041，最低声明支持 Windows 10 1809（17763）。发布先生成独立版本目录，安装前核对 ZIP SHA256、可执行文件版本和运行时全部文件哈希，再备份并替换正式安装。已归档的正式版 ZIP、校验值和发布记录保持不变。

实际检查及待人工验收项目见 `docs/MANUAL-ACCEPTANCE-v1.2.0.md`。本次未使用用户真实账号完成手机授权；无声技术验证不代表人工听感、高 DPI 或不同 Windows 版本均已实机验收。
