# v1.1.1 验收

所有 GUI 检查使用 `artifacts/gui-v1.1.1` 独立且静音的数据目录，用户的正式曲库和正在运行的旧版实例保持原状。

已执行：

- 860×600 小窗口，检查导航图标风格、居中、底栏播放按钮、账号入口与账号列表。
- QQ 游客实际播放，打开 30 首队列，观察连续播放和自动换曲，已加载的可见封面不再回退默认图片；队列行的自动化标识保持稳定。
- 网易云、QQ、酷狗真实二维码获取、等待扫码和取消，三个平台均通过。扫码成功后的协议、取消竞态与平台隔离使用固定测试验证，未使用用户账号完成手机授权。
- DPAPI 凭证加密、读取、单平台退出、并发写入和损坏文件保留；队列反复更新不发生集合重置、移动插入保留行身份。

发布前必须通过：Release 构建、完整 .NET 回归、全部 Node 网关测试、发布包版本与文件哈希核对。

由用户完成：手机确认授权后核对账号名称、退出与重启恢复；各平台实际账号的版权和会员歌曲权限。高 DPI、不同显示器和人工听感仍需实机覆盖。
