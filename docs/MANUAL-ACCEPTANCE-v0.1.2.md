# 猫娘播放器 v0.1.2 人工验收

## 一、启动程序

启动：

`<publish-directory>\win-x64\NekoPlayer.exe`

## 二、程序图标

1. 确认 EXE 文件显示新的猫娘图标。
2. 启动后确认任务栏显示同一图标。
3. 确认主窗口标题栏和左侧品牌区显示新图标。
4. Windows 图标缓存可能让资源管理器暂时显示旧图标，可重启资源管理器后复查。

## 三、首页和歌词

1. 首页“快速开始”只剩两项。
2. 不再显示“同名 LRC 会自动加载”的快速开始说明。
3. 正在播放页面的本地歌词、同步和高亮功能仍然存在。

## 四、真实导入

1. 进入“本地音乐”。
2. 点击“添加文件夹”。
3. 选择：`<temporary-audio-directory>`。
4. 确认导入期间出现进度条、当前阶段、当前文件名和数量统计。
5. 导入过程中切换首页、正在播放和设置页面，再切回本地音乐。
6. 确认页面没有卡住、空白或长时间未响应，底部播放栏仍可操作。
7. 导入结束后确认两首 MP3 均显示真实歌名、歌手、专辑和时长。
8. 确认列表没有演示歌曲、随机歌曲或其他虚构内容。
9. 确认 LRC、PNG、TXT 等文件没有显示为歌曲。
10. 确认导入结果数量正确，且歌曲显示前不会提前提示完整成功。
11. 再次导入同一文件夹，确认不会创建重复歌曲。
12. 第二次结果应提示歌曲已存在或没有新增，不能错误显示“新增 2 首”。
13. 在搜索框分别搜索两首歌曲；不匹配时应显示无结果状态。
14. 清空搜索词后，两首真实歌曲应重新可见。

## 五、播放回归

1. 双击歌曲播放。
2. 检查暂停、恢复、Seek、上一首、下一首和快速切歌。
3. 关闭程序后确认没有残留声音，程序正常退出且未崩溃。
