# 猫娘播放器 v0.1.4 人工验收

启动程序：

`<publish-directory>\win-x64\NekoPlayer.exe`

## A. 真实鼠标进度条

1. 播放第一首歌曲并等待 5 秒。
2. 抓住滑块拖到约 30%，松开后确认声音和时间跳到对应位置。
3. 再拖到约 60%，确认第二次拖动仍有效且不会被拉回旧位置。
4. 点击轨道约 45% 位置，确认可以跳转。
5. 暂停后拖动，确认仍保持暂停；恢复后从目标位置继续。
6. 分别在缩小窗口、普通窗口和最大化窗口下重复一次。
7. 人工听辨 Seek 后是否有爆音、杂音、明显延迟或旧位置残音。

## B. 停止后重播

1. 播放歌曲，点击停止，确认进度归零且主按钮显示播放图标。
2. 点击播放，确认当前歌曲从头重新播放。
3. 暂停后点击停止，再点击播放，确认仍能从头播放。

## C. 歌单添加

1. 进入“我的歌单”，选择已有歌单，点击“添加歌曲”。
2. 搜索并单选一首歌曲，确认添加成功且详情立即刷新。
3. 再多选歌曲批量添加，确认显示新增和跳过数量。
4. 重复添加同一歌曲，确认歌单不出现重复项。
5. 分别从本地音乐、喜欢的歌曲、最近播放、播放队列和正在播放页测试“添加到歌单”。

## D. 导航和图标缩放

1. 对首页、本地音乐、正在播放、最近播放、喜欢的歌曲、我的歌单和设置，分别点击行左侧、图标与文字之间、文字、文字右侧空白和最右侧。
2. 确认每个区域只导航一次，Hover/Pressed/Selected 背景覆盖整行。
3. 缩小、放大、最大化和恢复窗口，确认图标在按钮中居中，不裁剪、不重叠，核心按钮始终可见。

## E. 播放队列

1. 添加多首歌曲并打开播放队列，确认序号从 1 开始且连续。
2. 点击非当前项的“立即播放”，确认播放目标歌曲，其他队列项和顺序保持不变。
3. 移除一个队列项，确认剩余序号重新连续，当前项高亮正确。

## F. 从音乐库移除

请只选择不再需要保留在播放器曲库中的记录；该操作不会删除磁盘音频文件。

1. 单选一首歌曲，点击“从音乐库移除”，确认文案明确说明不删除磁盘文件。
2. 先取消，确认歌曲仍在；再次操作并确认，检查曲库记录消失。
3. 在资源管理器确认原音频文件仍存在。
4. 重新导入后多选两首，批量移除，确认只影响选中歌曲。
5. 若移除当前播放歌曲，确认播放安全停止、当前项清空且不会自动播放下一首。

## G. 首页、设置与退出

1. 首页问候应符合本地时间：05:00～10:59 早上好，11:00～12:59 中午好，13:00～17:59 下午好，18:00～22:59 晚上好，其余显示夜深了。
2. 打开设置并滚动到底部，确认显示精确文字“创作者：梦怀殇”和应用版本 0.1.4。
3. 通过标题栏正常关闭程序，在任务管理器确认没有 NekoPlayer、ffmpeg 或 ffprobe 残留进程。

## 问题反馈模板

- Windows 版本：
- 显示缩放比例：
- 进度条能否拖动：
- 轨道能否点击跳转：
- 第二次拖动是否仍有效：
- 暂停状态 Seek 是否保持暂停：
- Seek 后是否有爆音或残音：
- 停止后能否重新播放并从头开始：
- 歌单单选/多选添加是否有效：
- 是否出现重复歌曲：
- 各页面添加到歌单是否有效：
- 导航整行是否可点击，哪个区域异常：
- 图标是否居中，缩放后是否异常：
- 队列序号与立即播放是否正确：
- 单曲/多曲移除是否有效：
- 磁盘文件是否仍存在：
- 首页问候语与创作者信息是否正确：
- 是否崩溃或有其他问题：
