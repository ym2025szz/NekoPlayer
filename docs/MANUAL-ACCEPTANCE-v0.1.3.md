# 猫娘播放器 v0.1.3 人工验收

启动路径：

`<项目目录>\artifacts\publish\win-x64\NekoPlayer.exe`

本轮自动测试和性能验证使用独立临时 SQLite。以下收藏、最近播放和清空操作会修改正式用户数据库，请先确认当前数据适合人工验收；“取消喜欢”不会删除音乐文件，“移除/清空最近播放”只删除播放历史。

## A. 窗口和布局

1. 以普通窗口启动，确认首页、顶栏和底部播放栏完整。
2. 缓慢缩窄到应用最小尺寸 860×600，确认导航收缩为图标栏，页面核心按钮、播放主按钮和进度条仍可见。
3. 拉宽到约 1000px，确认进入 Standard；拉宽到 1200px 以上，确认进入 Wide。
4. 最大化窗口，再恢复窗口，确认页面不空白、搜索词和当前页面不丢失、音乐不中断。
5. 在本地音乐、喜欢、最近播放、歌单、正在播放和设置页分别滚动，确认主体可以滚动且顶栏、底栏稳定。
6. 检查长歌名、长歌手和长专辑名使用省略或换行，不把播放、爱心和队列按钮挤出窗口。
7. 打开、关闭播放队列；在 Compact 下确认抽屉可覆盖显示且可关闭。

## B. 导航栏

1. 依次点击首页、本地音乐、正在播放、最近播放、喜欢的歌曲、我的歌单、设置。
2. 对每项分别点击图标、文字和二者之间空白区域，确认整个 46px 高矩形都能切页。
3. 确认所有导航项高度、宽度、Padding、圆角和图标起始位置一致。
4. 确认当前页有背景与左侧青色选中竖条。
5. 在 Compact 下悬停每个图标，确认 ToolTip 能说明目标页面。

## C. 收藏

1. 在本地音乐页选择一首未收藏歌曲，确认显示空心灰青爱心，ToolTip 为“添加到喜欢”。
2. 点击爱心，确认变为实心粉红 `#FF5D7D`，并出现“已添加到喜欢” Snackbar。
3. 进入喜欢页面，确认该歌曲存在；若它正在播放，确认底部播放栏爱心同步。
4. 检查最近播放、队列或歌单中的同一歌曲，确认爱心状态同步。
5. 在喜欢页面点击实心爱心，确认歌曲立即从喜欢页面移除，但仍在本地音乐，当前播放不停止。
6. 在 Snackbar 有效期内点“撤销”，确认歌曲重新出现且爱心恢复。
7. 再次完成一次收藏或取消，正常关闭并重启程序，确认最终状态持久化。

## D. 最近播放

1. 播放两首测试歌曲，进入最近播放，确认按最后播放时间倒序且同一歌曲只显示最新条目。
2. 检查时间显示为“刚刚 / X 分钟前 / X 小时前 / 昨天 / 具体日期”中的合理形式。
3. 点击一条记录的“从最近播放中移除”，确认页面立即刷新并显示 Snackbar。
4. 确认音乐文件、曲库 Track、收藏、歌单、队列和正在播放状态不变。
5. 点击“撤销”，确认记录及其时间信息恢复。
6. 点击“清空最近播放”，确认对话层文案为：“这只会清除播放记录，不会删除歌曲文件、收藏、歌单或播放队列。”
7. 先点“取消”或按 Esc，确认历史不变。
8. 若确定允许修改正式历史，再次打开并点“清空记录”，确认页面进入 Empty；随后复查曲库、收藏、歌单和队列未变化。

## E. 进度条 Seek

1. 播放第一首测试 MP3，确认进度条自动移动。
2. 按住滑块拖到歌曲中段，确认时间文本显示预览位置，滑块不会被播放器的定时 Position 更新拉回。
3. 松开滑块，确认只在最终位置执行跳转，随后继续播放。
4. 点击轨道另一位置，确认可以跳转。
5. 暂停歌曲，拖动或点击进度条，确认 Seek 后仍保持暂停；再恢复播放，确认从新位置继续。
6. 快速连续拖动几次，确认没有明显卡顿、多个 FFmpeg 同时残留或旧位置声音回灌。
7. 没有当前歌曲或 Duration=0 时，确认进度条禁用。
8. 人工听辨跳转后是否有爆音、杂音、残音或听感错位；技术验证不能替代此项。

## F. 播放主按钮

1. 正在播放时，按钮显示“暂停”PathIcon，ToolTip 为暂停；点击后歌曲暂停。
2. 已暂停时，按钮显示“播放”PathIcon；点击后恢复。
3. 切歌、加载和 Seek 时，确认按钮显示忙碌状态并暂时禁止重复提交。
4. 停止后有当前歌曲时，确认显示播放动作；发生播放错误时确认可重试并有错误文字。
5. 检查按钮图标始终表达“点击后执行的动作”，没有播放/暂停反转。

## G. 快捷键和无障碍

1. 在普通页面按 Space，确认播放或暂停。
2. 按 Ctrl+F，确认搜索框聚焦且文本被选中。
3. 按左右方向键，确认前后 Seek 约 5 秒；Shift+左右方向键约 15 秒。
4. 在搜索输入框中输入空格，确认不会触发播放。
5. Slider 聚焦时按方向键，确认由 Slider 自身处理，不被窗口快捷键抢夺。
6. 打开队列或确认层后按 Esc，确认关闭最上层。
7. 使用 Windows 讲述人或 Accessibility Insights 抽查播放按钮、爱心、最近播放移除和搜索框名称。

## H. 文件不存在

1. 如方便，请在临时测试环境中让一条 Track 指向不存在文件，不要移动或删除珍贵音乐。
2. 确认行变灰并显示“文件不存在”，播放按钮不可用或点击后给出提示。
3. 确认没有启动 FFmpeg、没有增加播放次数或最近播放，也没有自动删除 Track、收藏或歌单关系。
4. 其他有效歌曲应继续正常播放。

## I. 尺寸和 DPI 矩阵

在当前可用环境中检查以下窗口尺寸：860×600（最小）、1280×720、1366×768、1920×1080。若设备允许，在 Windows 100%、125%、150%、175% 缩放下重复 A、B、E、F 的关键步骤。

自动化未永久修改系统 DPI，也没有伪造 125%～175% 的视觉结论；无法覆盖的比例请记录为人工待验收。

## J. 退出和进程

1. 通过窗口关闭按钮或 Alt+F4 正常退出，不要用任务管理器强制结束。
2. 确认退出后任务管理器中没有 `NekoPlayer`、本轮 `ffmpeg` 或 `ffprobe` 残留。
3. 重启后确认窗口尺寸、音量、队列和收藏状态按预期恢复，且启动时不会自动发声。
