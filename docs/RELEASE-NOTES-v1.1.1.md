# v1.1.1

修复用户反馈的登录入口缺失、图标不居中和播放队列封面闪烁。

- 右上角“账号授权”按钮进入设置顶部的“账号与授权”。网易云、QQ 音乐、酷狗提供二维码登录、状态显示、刷新、取消和退出；手机端由用户确认授权。酷我和汽水显示目前尚无稳定账号接口。
- 登录凭证保存在当前 Windows 用户专属的 DPAPI 加密文件中，与普通 settings.json 分开。网关只在内存中持有平台凭证，平台之间按请求隔离；重启网关会恢复授权。QQ 的恢复状态明确标注为“已恢复凭证”，实际播放时由平台检验权限。
- 登录或退出后，搜索缓存按账号版本隔离，并重新确认已有结果的播放权限。
- 队列行改为增量同步，播放进度更新不再重建队列；切歌和调序保留行身份。同一封面调整解码大小时保留原图。
- 导航图标采用统一的 24 单位线条网格；小窗口隐藏文字后不再留空白列。小尺寸播放按钮统一无内边距，修复图标被压缩和偏移。
- 队列不再显示空版本的多余分隔点；当前软件说明更新为本地与在线音乐播放器。

验证记录见 `docs/MANUAL-ACCEPTANCE-v1.1.1.md`。真实账号的手机确认和会员歌曲播放需要用户自身账号完成，本次未替用户登录。
