# 猫娘播放器 v1.0.0 人工验收

最终启动路径：

`<项目目录>\artifacts\publish\win-x64\NekoPlayer.exe`

验收前请正常关闭其他 NekoPlayer 实例。以下操作只验证界面和现有功能；“从音乐库移除”不会删除磁盘音频文件，但仍请认真确认目标歌曲呀。

## A. 默认歌曲封面

1. 启动程序，打开“本地音乐”。
2. 找到一首没有内嵌封面的歌曲，确认列表显示猫娘播放器图标，而不是空白、音符渐变占位或错误图标。
3. 播放该歌曲，确认底部播放栏显示同一猫娘播放器图标。
4. 打开“正在播放”，确认大封面仍显示同一图标。
5. 打开“最近播放”，确认该歌曲仍显示相同默认图标。
6. 将该歌曲添加到歌单，打开歌单详情，确认仍显示相同默认图标。
7. 打开播放队列和歌单歌曲选择器，确认无封面歌曲显示相同图标。
8. 分别缩小到 Compact、恢复 Standard、放大到 Wide 并最大化窗口，确认默认封面没有横向/纵向变形、消失、闪白或错位。
9. 正常关闭并重新启动程序，确认无须重新导入即可继续显示默认封面。
10. 如存在带有效真实封面的歌曲，确认真实封面优先显示，没有被默认图标覆盖。

## B. 收藏视觉

1. 找到一首未收藏歌曲，确认爱心是空心轮廓，颜色为灰青色。
2. 点击爱心，确认立即变为实心爱心，颜色明显变为粉红色。
3. 将鼠标悬停在爱心上，确认未收藏仍是空心灰青系，已收藏仍是实心粉红系。
4. 按住鼠标再松开，确认 Pressed 状态没有把收藏颜色反转。
5. 打开“喜欢的歌曲”，确认歌曲存在且显示实心粉红心。
6. 检查正在播放页、底部播放栏、最近播放、歌单详情、播放队列和歌曲选择器中的同一首歌，确认状态同步。
7. 点击任意同步入口取消喜欢，确认所有位置恢复为空心灰青爱心。
8. 再次收藏并正常重启程序，确认收藏状态持久化；随后可按需要恢复原状态。
9. 没有当前歌曲时，确认底部收藏按钮不可用，但仍可辨认其未收藏轮廓。

## C. 版本信息

1. 检查左下角，确认只显示 `v1.0.0`。
2. 确认左下角没有版本名称、版本介绍、开发阶段说明、“正式版”副标题或“响应式交互版”。
3. 打开“设置”并滚动到“程序与数据”，确认版本区域只显示 `v1.0.0`。
4. 确认没有同时向普通用户展示 ProductVersion 和 FileVersion。
5. 确认设置页仍显示精确文字“创作者：梦怀殇”。
6. 确认当前 UI 不再显示旧版本号 `0.1.4`。

## D. 核心功能回归

1. 导入一首本地歌曲，确认导入结果与曲库列表一致。
2. 播放歌曲，执行暂停和恢复。
3. 使用真实鼠标拖动进度条，再点击轨道跳转，确认位置正确更新。
4. 点击停止，再次播放，确认从头重新播放。
5. 添加一首或多首歌曲到歌单，确认重复关系仍会跳过。
6. 打开播放队列，确认序号从 1 连续显示，并点击“立即播放”。
7. 点击左侧导航行右侧空白区域，确认仍能切换页面。
8. 搜索并切换排序，确认封面和收藏视觉不丢失。
9. 正常关闭程序，确认没有异常对话框或卡死。
